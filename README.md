# 📖 Overview

Airbnb has transformed the hospitality industry by enabling individuals to rent properties to travelers worldwide. Understanding listing prices, room availability, neighbourhood trends, and customer reviews can help both hosts and travelers make informed decisions.

This project performs a complete **Exploratory Data Analysis (EDA)** on the **Airbnb New York City 2019** dataset using Python and industry-standard data analysis libraries.

The objective is to discover hidden patterns, identify trends, and generate actionable business insights through data visualization.

---

# 🎯 Objectives

* Understand Airbnb listing patterns
* Clean and preprocess real-world data
* Perform exploratory data analysis (EDA)
* Discover pricing trends across neighbourhoods
* Compare room types and availability
* Analyze customer reviews
* Generate business insights using visualizations
* Present findings with interactive charts
